# Security

Thanks for taking the time to look. Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/wielorzeczownik/phalcon-inertia/security/advisories/new) instead of a public issue, so there's a chance to fix them first. You'll be credited in the release notes unless you'd rather not be. Only the latest release gets fixes.

It helps to mention which part is affected (page rendering, CSRF, route export, SSR) and the PHP and Phalcon versions.
